## About Me

I'm currently transitioning from software pre-sales and product management into full-time software development.

My experience combines business strategy with technical execution: from managing enterprise software solutions and technical demos to building APIs, integrations, automation tools, dashboards, and back-end applications.

I'm finishing my degree in Systems Analysis and Development at FIAP, where I've built REST APIs in Java and .NET, mobile apps, Oracle PL/SQL and MongoDB data layers, IoT pipelines, and cloud deployments on Azure. My final project, **Vê AI**, is a generative AI mobile app that describes the surroundings to visually impaired people.

Strong interests in:

- Back-end Engineering
- Software Architecture
- Generative AI projects (LLMs, RAG, AI agents)
- Infrastructure & Cloud
- DevOps
- Cybersecurity
- Systems Integration
